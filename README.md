# Star Security Services

A professional corporate services website with a fully functional Admin Panel built using ASP.NET Core MVC.

## Tech Stack
- ASP.NET Core MVC
- C#
- Entity Framework Core (DB First)
- SQL Server
- Bootstrap 5

## Features
- Public-facing website showcasing company services
- Admin Panel with full CRUD operations
- Employee management module
- Client management module
- Vacancy management module
- Service management module
- Role-based access control
